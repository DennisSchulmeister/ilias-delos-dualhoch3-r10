DualHoch3: ILIAS Skin and Style
===============================

This is a customized version of the ILIAS Delos system skin and style
for the DualHoch3 project and its ILIAS systems running on [dualhoch3.de](https://dualhoch3.de).

This repo follows the recommended best-practices by the ILIAS developers
to fork the Delos style from https://github.com/ILIAS-eLearning/delos
and modify the SASS files.

Branches
--------

This skin is developed for ILIAS 10.5. Thus, the repo was forked from the
`release_10` upstream branch like so:

```sh
git clone --branch release_10 --single-branch https://github.com/ILIAS-eLearning/delos.git ilias-delos-dualhoch3-r10
```

Once we move to ILIAS 11 or later, a new style on the then current Delos
style will be created, to minimize the risk of merge conflicts and other
fragile merge activities.
